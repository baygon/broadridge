# Running

The app reads from the mock API at `http://localhost:3000`, so **start the API first**.

## 1. Mock API (port 3000)

```bash
cd mock-interview-api
npm install
npm start
```

## 2. Angular app (port 4200)

In a second terminal:

```bash
cd package-viewer
npm install
npm start
```

Then open http://localhost:4200.
